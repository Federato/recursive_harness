# The rating engine, one file at a time

Twenty notebooks walking through the engine's code. Every example runs.

**Open it:** double-click `start-notebooks.bat` (Windows) or `start-notebooks.command` (Mac). Start
at `00-index.ipynb`.

**Short on time:** `05` (which rulebook applies), `11` (ISO's 54 instructions), `16` (submission in,
premium out).

**Cells are blank until you hit Run All.** On purpose — saved results would put ISO's licensed
numbers in our repo.

**Without ISO's files, fourteen of the twenty stop partway.** Not broken, just nothing to read.
These six run fully: `02`, `03`, `08`, `09`, `15`, `19`. All twenty are readable either way.

**The point:** search the engine for "deductible" and you get one result, and it isn't arithmetic.
It doesn't reimplement ISO's rules, it runs them. That's why 5,000 lines cover 51 states and an ISO
update is a file drop, not a project.
