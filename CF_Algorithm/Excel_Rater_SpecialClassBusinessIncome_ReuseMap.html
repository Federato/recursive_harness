Special Class Business Income — what you can copy, step by step

Written: 2026-09-16. Source: a rule-by-rule diff of CommercialPropertySpecialClassRules.Rule.xml (the building item) against CommercialPropertySpecialClassBusnIncomeRules.Rule.xml (this group), CW 20260601 V01 — 68 rule names appear in both files, 40 only in Business Income, 58 only on the building side. Every verdict below comes from reading both bodies, not from the name matching.

Read this first. A rule with the same name in both files is not evidence of the same value. Three of the shared names are literal Copy rules, four are independent lookups that happen to land on the same number, and two share a table but gate on a different endorsement record. The name tells you nothing; the body does.

The three verdicts

VerdictMeansIn the workbook
COPYThe filed rule is itself a Copy, or every input is borrowed, so the two values are equal by constructionA cell reference. Safe.
SHARE THE TABLESame matrix and same keys, but the gate is a different input — the looked-up number matches, the applied value may not One shared lookup block, own IF around it
BUILD OWNDifferent table, different keys, or the concept does not exist on the other sideIts own block. Copying is wrong today, not just fragile.

Special — step by step

Six steps on paper, but the rate chain is the same two-term product as Broad with one factor after it. Nothing here is copyable from the building side — both tables are different, not just the keys.

StepValueFrom Building?Why
1SpecialTheftExclusionIndicatorBUILD OWN Gates on CommercialPropertyTheftExclusionSpclClassBusnIncome — its own endorsement record, distinct from the building's. Same two-record pattern as S-1 and S-2.
2SpecialTheftExclusionFactorBUILD OWN Different table. Business Income reads SpecialLeaseHoldTimeElementTheftExclusionFactor (State + ApartmentCondoIndicator, hardcoded "No") → 0.86. The building reads SpecialBldgTheftExclusionFactor (State + "Y") → 0.88. Same rule name, same datadef name, two matrices.
3SpecialBaseRateBUILD OWN Different table again. Business Income: SpecialFormIncldgTheftTimeElementBaseRate, keyed State + "Frame" + CovType + "Other than Apartments and Condominiums" — three of the four keys are literals. Building: SpecialBuildingRate, keyed State + "Y".
4SpecialRateBUILD OWN SpecialBaseRate × LossCostMultiplier — same shape both sides, different first term.
5SpecialCauseOfLossAdjustmentSAME SHAPE ONLY SpecialRate × SpecialTheftExclusionFactor, an unconditional Product in both files — byte-identical logic. Copy the formula, never the inputs.
6FinalSpecialRateDO NOT COPY THE FORMULA Business Income: Copy SpecialCauseOfLossAdjustment. Same story on the factor: SpecialLeaseHoldTimeElementTheftExclusionFactor files Yes → 0.96 and No → 0.86, and only 0.86 is reachable. State coverage. SpecialFormIncldgTheftTimeElementBaseRate has 24 CW rows and only 2 states filing their own, so it is effectively countrywide. SpecialLeaseHoldTimeElementTheftExclusionFactor is CW-only, no state filings. Contrast the building side: SpecialBuildingRate has zero CW rows — 45 states file it, FL and PR file nothing — and SpecialBldgTheftExclusionFactor is state-filed in 31. The two chains do not even have the same countrywide-vs-state shape.

The traps, ranked

  1. Same rule name, different table. SetSpecialBaseRate reads SpecialBuildingRate on the building and SpecialFormIncldgTheftTimeElementBaseRate here. SetSpecialTheftExclusionFactor reads SpecialBldgTheftExclusionFactor vs SpecialLeaseHoldTimeElementTheftExclusionFactor. Two of the most copy-able-looking names on the list are the two that are flatly wrong to copy — 0.86 vs 0.88 on the theft factor, and two unrelated base-rate matrices. See the Special section.
  2. Same table, different key. Broad reads the same BroadFormBaseRate matrix on both sides and the same hardcoded "Frame" — but a different CovType key, so a different row. 0.015 vs 0.011 vs 0.023 countrywide.
  3. Same table, different gate. Vandalism and wind/hail — S-1 and S-2.
  4. Same everything, but the other side applies an extra multiplier. StdPropPolGroupIIFactor. Copy the formula and you inherit it.
  5. FL. Vandalism becomes a subtracted rate, and FL files no BasicGroupIIRate rows at all.
