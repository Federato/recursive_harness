Building — the full 9-step chain

Calc_Building_Special, one row per building — the flattest loss cost of any form built so far: one flag (ClassCode = "1150"), no other rating dimension.

TheftExclusionFactor =
    LookupSpecialBldgTheftExclusionFactor(State|CW, "Y")   if CauseOfLoss = "Special" and TheftExclusionAttached = "Y"   (CW 0.88)
    else: 1.0

BaseRate =
    if CauseOfLoss = "Special":
        if ClassCode = "1150": LookupSpecialBuildersRiskRate(State|CW, "Y")    (CW 0.015, resolves all 47 states)
        elif State = "FL":     LookupFLSpecialBuildingRateResidentialOrNonRes(ClassCode)   ★ FL-only state-specific rule -- 0.03 for 21 named residential class codes, 0.035 for everything else. Corrected 2026-09-09.
        else:                  LookupSpecialBuildingRate(State|CW, "Y")        CW header-only, but 45 of 46 non-FL states file their own row (built 2026-09-09)
    else: 0.0

Rate = BaseRate × LCM   (round 3dp -- no addends, no territory, no protection class, no construction)

COLAdj = Rate × TheftExclusionFactor × RoofSurfacingACVFactor   (round 3dp -- always recomputes, no null-guard)

LOIFactor =
    <blanket copy>                       if Bldg_IncludedInBlkt = "Yes" and BlktIDNum > 0
    elif Bldg_CovType = "Builders Risk": LookupBroadSpecialLOIFactorWithArgs(...) or 0.0 if limit absent
    elif Bldg_CovType not in ("Leasehold Interest","Legal Liability","No Coverage"):
        LookupBroadSpecialLOIFactorBldg(State|CW, Bldg_Limit)
    else: 1.0

AdjustedRate = COLAdj × CoinsuranceFactor × LOIFactor   (shared CoinsuranceFactor, no Special-specific coinsurance rule)

DeductibleByLocationFactor =
    LookupDeductibleByLocationFactor(...)   if a by-location record exists and TheftDeductible not blank/N-A
    else: 1.0    (theft-driven, not the wind/hail-driven version Basic Group II uses)

DeductibleFactor =
    LookupDeductibleFactor(TheftDeductible, SpecialIncludingTheftTotAmtInsurance, "Other Cause Of Loss")
        if TheftExclusionAttached <> "Y" and TheftDeductible not in ("","Not Applicable","250") and TheftDeductible <> Deductible
    elif Deductible = "250" and TheftDeductible = "250": LookupDeductible250Factor("Special", ...)
    elif Deductible = "Not Applicable": 1.0
    elif Deductible <> "": LookupDeductibleFactor(Deductible, SpecialTotAmtInsurance, "Other Cause Of Loss")
    ★ corrected: SpecialTotAmtInsurance = StructureLimitToUse + OccupancyTotSpecialAmtInsuranceSum + SpecialClassRiskSpecialTotAmtInsurance -- Bldg limit PLUS every Contents item's limit at the location PLUS Special Class Risk, Special-scoped. Same combined-location-total pattern as plain TotAmtInsurance. Previously documented as Bldg_Limit alone, matching the same wrong simplification made for BGI/BGII/Broad; backlogged until Contents is built.

FinalRate = AdjustedRate × DeductibleByLocationFactor × DeductibleFactor × MultiResidentialPropSpecialCreditFactor

Bldg_Premium =
    if Bldg_CovType in ("Building","Builders Risk","Improvements and Betterments","Condominium Association")
       and CauseOfLoss = "Special" and Bldg_IncludedInBlkt = "No":
        FinalRate × (Bldg_Limit/100) × PackageMod × MultiPremiumDispersion × IRPM
          × CyberExclFactorSpecial × CyberExclCOLExcptnsFactorSpecial
          [nested Product, DecimalPlaces=0 at each step -- no outer ROUND(), unlike Basic Group I/II/Broad]
    elif Bldg_CovType = "Legal Liability" and CauseOfLoss = "Special": [not built this pass -- uses raw Rate, not COLAdj]
    elif Bldg_IncludedInBlkt = "Yes" and BlktCauseOfLossValue = "Special": [blanket, not built this pass]
    else: 0.0
⚠No null-guard on COLAdj — unlike the Basic forms' cause-of-loss-adjustment rules, Special's version always recomputes rather than short-circuiting when a factor is absent. Not a bug by itself, just a different pattern worth knowing before comparing this chain line-by-line against Basic Group I/II.

Contents — the full 14-step chain

Calc_Contents_Special, one row per building — the richest input set of any form built so far: two base-rate keys, its own territory multiplier, two protective-safeguard credits, and a locally-computed deductible factor. (Numbered 1–12 below to match every distinct value computed; ISO's own count of 14 includes two occupancy-category prerequisite steps this workbook treats as plain Locations_Buildings columns rather than derived values.)

DeductibleByLocationFactor = (step 1 -- Copy'd from an ancestor in ISO's rules; build as the same local logic Building's tab uses, documented deviation)

DeductibleFactor = (step 2 -- the ONLY deductible factor of any Contents form that is genuinely computed locally, not Copy'd)
    LookupDeductibleFactor(TheftDeductible, SpecialIncludingTheftTotAmtInsurance, "Other Cause Of Loss")
        if SpecialTheftExclusionIndicator = 0 and TheftDeductible not in ("","Not Applicable","250") and TheftDeductible <> Deductible
    elif Deductible = "250" and TheftDeductible = "250": LookupDeductible250Factor("Special", ...)
    elif Deductible = "Not Applicable": 1.0
    elif Deductible <> "": LookupDeductibleFactor(Deductible, SpecialTotAmtInsurance, "Other Cause Of Loss")
    (same 4-branch shape as Building's, keyed on an indicator rather than reading TheftExclusionAttached directly)

TheftExclusionFactor = (step 3)
    if CauseOfLoss = "Special" and TheftExclusionAttached = "Y":
        LookupSpecialPrsnlPropTheftExclusionFactor(State|CW, PP_OccupCategory)   if PP_OccupCategory <> ""   ★ no CW row filed
        else: 0.0
    else: 1.0

BaseRate = (step 4)
    LookupSpecialPrsnlPropRate(State|CW, PP_OccupCategory, PP_OccupCategoryRiskSeverity)
        if CauseOfLoss = "Special" and PP_OccupCategory <> "" and PP_OccupCategoryRiskSeverity <> ""   ★ no CW row filed
    else: 0.0

TerrMultiplier = (step 5 -- no Building equivalent at all)
    LookupTerritoryMultiplier(State|CW, PP_SpecialRatingTerr)   if CauseOfLoss = "Special" and PP_SpecialRatingTerr <> ""   ★ no CW row filed
    else: 0.0

Rate = (step 6)
    0.0   if CauseOfLoss <> "Special"
    else TerrMultiplier × (BaseRate × LCM)   (round 3dp -- multiplier applies to the whole product, not to BaseRate alone)

COLAdj = (step 7 -- no roof-surfacing factor, none exists anywhere in the Contents ruleset)
    0.0   if PP_CovType = "Valuable Papers and Records - Other Than Electronic Data"
    else Rate × TheftExclusionFactor

WatchmanCreditFactor = (step 8 -- Contents-only, no Building equivalent)
    PP_WatchmanCreditFactor   if SpecialTheftExclusionIndicator = 0 and PP_ProtectiveSafeguardsOnFile = "Y"
    else: 1.0

BurglaryAlarmCreditFactor = (step 9 -- same gate and shape as step 8, reading PP_BurglaryAlarmCreditFactor)

LOIFactor = (step 10 -- three-way)
    <blanket copy>   if PP_IncludedInBlkt = "Yes"
    elif PP_CovForm not in ("Legal Liability Coverage Form","Tobacco Sales Warehouse Coverage Form") and OccupSpecialTotAmtInsurance > 0:
        LookupBroadSpecialLOIFactorPrsnlProp(State|CW, OccupSpecialTotAmtInsurance)
    else: 1.0

AdjustedRate = COLAdj × CoinsuranceFactor × WatchmanCreditFactor × BurglaryAlarmCreditFactor × LOIFactor   (step 11 -- two more multiplicands than Building's equivalent step)

FinalRate = AdjustedRate × DeductibleByLocationFactor × DeductibleFactor   (step 12 -- no multi-residential credit, consistent with every Contents form)

PP_LimitToUse =
    PP_AlcoholicBeveragesTaxExclusionLimit   if PP_AlcoholicBeveragesTaxExclusion = "Y"
    else PP_Limit   (Contents-only sublimit override, CP 12 11 -- no Building equivalent or column at all)

PP_Premium =
    if PP_CovForm not in ("Legal Liability Coverage Form","Tobacco Sales Warehouse Coverage Form")
       and CauseOfLoss = "Special" and PP_IncludedInBlkt = "No":
        FinalRate × (PP_LimitToUse/100) × PackageMod × MultiPremiumDispersion × IRPM
          × CyberExclFactorSpecial × CyberExclCOLExcptnsFactorSpecial   (same nested-Product rounding as Building)
    elif PP_CovForm = "Legal Liability Coverage Form" and CauseOfLoss = "Special":
        [not built this pass -- uses COLAdj (SpecialCauseOfLossAdjustment), NOT the raw rate, unlike Building's Legal Liability branch]
    elif PP_IncludedInBlkt = "Yes" and BlktCauseOfLossValue = "Special": [blanket, not built this pass]
    else: 0.0
⚠Don't copy Building's Legal Liability formula onto Contents when either gets built. Building's branch uses the raw, unadjusted SpecialRate — theft-exclusion and roof-surfacing never reach it. Contents' equivalent branch uses SpecialCauseOfLossAdjustment, which already includes the theft-exclusion factor. A naive copy-and-rename would silently get this wrong.
⚠PP_WatchmanCreditFactor and PP_BurglaryAlarmCreditFactor are not rate-table lookups. They're copied directly from the insured's protective-safeguards schedule entry (a CommercialPropertyBurglaryAndRobberyProtectiveSafeguards record) — enter the schedule's own values on Locations_Buildings rather than adding a Rate_Tables block for them.
