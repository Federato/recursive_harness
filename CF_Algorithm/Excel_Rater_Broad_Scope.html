Building — the full 6-step chain

Calc_Building_Broad, one row per building.

BaseRate =
    if CauseOfLoss = "Broad" and ConstructionType <> "":
        if ClassCode = "1150":
            LookupBroadFormBaseRate(State|CW, ConstructionType, "BldrRisk")
        else:
            LookupBroadFormBaseRate(State|CW, ConstructionType, "Bldg")
    else:
        0.0

Rate = BaseRate × LCM   (round 3dp -- no addends, no other factors, the simplest Rate of any form built so far)

LOIFactor =
    <blanket copy>                       if Bldg_IncludedInBlkt = "Yes" and BlktIDNum > 0
    elif Bldg_CovType = "Builders Risk":
        LookupBroadSpecialLOIFactorWithArgs(...) or 0.0 if limit absent
    elif Bldg_CovType not in ("Leasehold Interest","Legal Liability","No Coverage") and Bldg_Limit <> "":
        LookupBroadSpecialLOIFactorBldg(State|CW, Bldg_Limit)
    else:
        1.0

AdjustedRate = Rate × RoofSurfacingACVFactor × CoinsuranceFactor × LOIFactor
    (no cause-of-loss-adjustment stage at all -- straight from Rate to here)

DeductibleFactor =
    LookupDeductible250Factor("Broad")                        if Deductible = "250"
    elif Deductible = "Not Applicable": 1.0
    elif Deductible <> "":  LookupDeductibleFactor(Deductible, TotAmtInsurance, "Other Cause Of Loss")
    else: 0.0   ★ blank deductible ZEROES the rate, not a 1.0 no-op
    ★ corrected: TotAmtInsurance = StructureLimitToUse + OccupancyTotAmtInsuranceSum + SpecialClassRiskTotAmtInsurance -- Bldg limit PLUS every Contents item's limit at the location PLUS Special Class Risk. NOT Bldg_Limit alone (was wrong here). Live rater still uses Bldg-only; backlogged until Contents is built.

FinalRate = AdjustedRate × DeductibleByLocationFactor × DeductibleFactor × MultiResidentialPropSpecialCreditFactor

Bldg_Premium =
    if Bldg_CovType in ("Building","Builders Risk","Improvements and Betterments","Condominium Association")
       and CauseOfLoss = "Broad" and Bldg_IncludedInBlkt = "No":
        round(IRPM × MultiPremiumDispersion × PackageMod × FinalRate × (Bldg_Limit/100), 0)
          × CyberExclFactorBroad × CyberExclCOLExcptnsFactorBroad
    elif Bldg_CovType = "Legal Liability" and CauseOfLoss = "Broad": [not built this pass]
    elif Bldg_IncludedInBlkt = "Yes" and BlktCauseOfLossValue = "Broad": [blanket, not built this pass]
    else: 0.0
⚠Blank deductible zeroes the entire rate — the same class of trap already found live in this project's own BasicGroupIILOIFactor/BCEG builds (a factor whose "no input" default is 0.0 instead of the usual 1.0 no-op). If Broad is ever wired into the rater, Deductible needs to be a required field, not an optional one with a sensible default.
⚠Both Legal Liability branches (Building and Contents) use the raw, un-adjusted Rate — not FinalRate or any coinsurance/LOI/deductible-adjusted value. Same pattern as every other form's Legal Liability branch, worth restating since Broad has no COL-adjustment stage to have skipped in the first place.

Contents — the full 5-step chain

Calc_Contents_Broad, one row per building — no Builders Risk branch, no roof factor, no local deductible rule at all.

LOIFactor = (computed FIRST -- order doesn't affect the math)
    <blanket copy>                                  if PP_IncludedInBlkt = "Yes"
    elif PP_CovForm not in ("Legal Liability Coverage Form","Tobacco Sales Warehouse Coverage Form")
         and OccupTotalLOIToUse > 0:
        LookupBroadSpecialLOIFactorPrsnlProp(State|CW, OccupTotalLOIToUse)
    else:
        1.0                                          (no Builders Risk branch, unlike Building)

BaseRate =
    LookupBroadFormBaseRate(State|CW, ConstructionType, "PersProp")   if CauseOfLoss = "Broad" and ConstructionType <> ""
    else 0.0    (always "PersProp" -- no class-code check at all)

Rate =
    0.0    if CauseOfLoss <> "Broad" or PP_ValuablePapers = "Y"
    else BaseRate × LCM   (round 3dp -- Valuable-Papers zeroing lives HERE, one stage earlier than Basic I/II since there's no COL-adjustment stage to carry it)

AdjustedRate = LOIFactor × Rate × CoinsuranceFactor   (no roof-surfacing factor, any branch)

FinalRate = AdjustedRate × DeductibleByLocationFactor × DeductibleFactor
    DeductibleFactor: same local Choose as Building's -- documented deviation, see §4

PP_Premium =
    if PP_CovForm not in ("Legal Liability Coverage Form","Tobacco Sales Warehouse Coverage Form")
       and CauseOfLoss = "Broad" and PP_IncludedInBlkt = "No":
        round(IRPM × MultiPremiumDispersion × PackageMod × FinalRate × (PP_Limit/100), 0)
          × CyberExclFactorBroad × CyberExclCOLExcptnsFactorBroad
    elif PP_CovForm = "Legal Liability Coverage Form" and CauseOfLoss = "Broad": [not built this pass]
    elif PP_IncludedInBlkt = "Yes" and BlktCauseOfLossValue = "Broad": [blanket, not built this pass]
    else: 0.0
⚠DeductibleFactor has no local rule anywhere in Contents' own ruleset — the source doc confirms it's read directly from an ancestor context, four levels up, with nothing local at all. This project's own documented convention (same treatment as Basic Group I §5 step 9, Basic Group II §5 step 11) is to build it as the same local Choose Building's chain already uses, with the same cell comment flagging the deviation. Given the CauseOfLossDeductible key-mismatch finding from the Basic Group II deductible review, this table also needs its own 47-state pull filtered to the correct group key before trusting it — not yet done for Broad.

⚠The DeductibleFactor key question deserves direct attention before building this form.
