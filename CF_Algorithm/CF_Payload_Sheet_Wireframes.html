Sheet 1 — Payload Export

One formula pattern covers the whole sheet. Your input tabs run one column per item; this sheet runs one row per item. Put the item's ordinal in column A, and every other cell is the same INDEX against a fixed input row: 
=INDEX('Location Inputs'!$C$26:$L$26, 1, $A20)
                        ^^^^^^^^^^^^        ^^^^
             the input row being read    the item ordinal in col A
Write it once per column, fill down. No cell address is ever hard-coded into the reader, so rows can be inserted freely later.

The Active column is the important one. Columns G–L of Location Inputs are placeholders — "Select", "State", 0. Without a gate the generator would emit ten locations when four are real, and ISO would either refuse or price six empty ones. Active tests the State cell against its placeholder text and Python skips every No row.

Rows 89, 91 and 93 look redundant today and are the whole point. ISO files two exclusion records — one on the Special Class item, one on its Business Income group. The rater has one Yes/No input driving both, which is backlog S-1 / S-2 / S-3. Giving each record its own Elected cell now, even though both point at the same input, means closing that backlog later is an input change, not a re-spec. Point them at separate inputs the day those inputs exist.

Record names in angle brackets are placeholders — lift the exact names from the harness's gate point 7 census (“every exclusion's endorsement record identified per datadef group”, passed on all eight closed chunks) rather than guessing them.

Build order

  1. Defaults first. Thirteen rows, literal values. Ten minutes, and it lets the reader be tested before the big sheet exists.
  2. Block skeletons next — just column A: the nine block names at rows 1, 5, 18, 31, 44, 57, 70, 76, 82, with the blank rows between. Gets the shape right before any formula is written.
  3. Then LOCATION in full, including Active. One block done end to end proves the INDEX pattern before it is repeated eight times.
  4. Then STRUCTURE, the largest. Write each column's formula in row 20 and fill down to row 29.
  5. Then blocks 4–8, which are the same pattern at smaller scale.
  6. RECORDS last.
  7. Tell me when any of it is in. It does not need finishing first — the reader fails loudly and names the missing block, so a half-built sheet returns a precise error, never a wrong premium.
Two things that will not break it. Inserting rows is safe — the reader finds each block by its name in column A and reads until the blank row, so adding an eleventh location or a fourth Special Class item needs no code change. Renaming an input label is safe too — the formulas point at cells, and the labels are only there for you to read.
