No loss cost, by rule: the whole chain is an ELP surrogate

Rule 45.E says "For rates, refer to company." ISO publishes no liquor loss cost, so the base rate is always the expected loss potential (ELP) times a loss cost multiplier that is itself a placeholder of 1. Every deductible factor is 0, also by rule (45.J.3). What ERC computes is a starting point a carrier is expected to replace.

Liquor needs its own policy record with subline "Liquor". Nothing else puts the coverage on the policy. The edition is picked the same way as every GL subline: all 51 jurisdictions run pre-2027 today. On 2027-04-01, 46 move to CW 2027, and CA, GA, NJ, NY and WA stay.

Pre-2027 chain
12 + 4

Rate-build and premium steps. Nine per-$1,000 premium bases, a "Refer To Co." basis that prices 0, and a policy-level minimum premium that is always 0.

CW 2027 chain
12 + 2

A new basis vocabulary with two per-$1,000 bases, the class code replacing the description as the gate, no minimum premium, and a $1 floor on a rounded-zero premium.

Stale basis in 2027
1000×

An active 2027 class sent with a pre-2027 basis such as "Gross Sales" falls to the per-unit branch and prices a thousand times too high, with no message.

What to notice

  • The premium basis decides the arithmetic: per $1,000, per unit, or a referral. It is the most consequential input on a liquor risk, and in 2027 its whole vocabulary changes.
  • Liquor borrows two Products tables: the claims-made multiplier and the minimum premium (at a hardcoded table letter "C"). The manual directs both.
  • Limits are "each common cause" and aggregate, with no " CSL" suffix in any edition. Illinois rates from its own table keyed on the aggregate alone, and Minnesota overrides the ILF rule with a sub-limit lookup.
New York disables claims-made liquor. NY's SetBaseRate requires an Occurrence form, and its claims-made rules are constant stubs. A claims-made liquor risk in NY prices 0 with no message. NY stays on pre-2027 at 2027-04-01.

What to notice

  • The class description gates the ELP, the ILF and the deductible. A risk with the code but no description gets ELP 0 and ILF 0 and prices 0, with no message.
  • The base rate needs a filled coverage form. Any value other than "Claims Made" takes the occurrence formula. Only a blank form gives 0.
  • Of the 21 zero deductible factors, ISO guards only the 10 "Per Claim" options with a message. A "Per Common Cause" deductible is priced as no deductible, silently (OI-44).
  • The minimum premium uses Products' table at letter "C", which is 0 everywhere. The top-up is always 0 on filed data.
Silent zeros, 2026-10-05. Six inputs price 0 with no message: a blank description, a blank coverage form, a blank or "Refer To Co." basis, a missing policy modifier, and any premium that rounds below 0.5. A Company class also prices 0, but ISO messages it. Underwriting mode adds R03 for the refer sentinel and R29 for Company classes.
R14 over-fires. The engine's zero-factor detector raises R14 on any liquor lookup that returns 0. Since "No Deductible" is a filed 0, every liquor risk is referred in underwriting mode, though the register meant only the ten unguarded Per Common Cause options.

What to notice

  • The premium rule sorts bases into three groups: blank or "Refer to Company", the two "Gross Sales of …" bases, and everything else, which is per unit. Any pre-2027 value falls into the per-unit group, including "Gross Sales" and the old "Refer To Co." spelling. On an active 2027 class that is a premium 1,000 times too high.
  • The $1 floor tests the rounded premium, as Premises and Products do (OCP tests the unrounded sum). So a blank basis, a refer basis, a blank form, a retired class and a tiny exposure all price at $1.
  • A blank class description no longer zeroes anything. The class code now gates the ELP, the ILF and the deductible.
  • The statistical-code rule still tests the old vocabulary, so reported exposure on the Gross Sales bases is 1,000× too large (OI-43). The premium is unaffected.
New finding, 2026-10-05. An active 2027 class rated with the pre-2027 basis "Gross Sales" priced at 681,200 against 681 with "Gross Sales of Alcoholic Beverages". The old "Refer To Co." spelling did the same. ISO raises no message. Underwriting mode refers it only through R14, which fires on every liquor risk anyway, and through R03 for the refer spelling.
vs. pre-2027. The rate build-up is identical apart from which field gates it. The minimum premium is gone, the floor arrives, and the basis vocabulary is replaced. Any submission or mapping that carries liquor bases across the 2027-04-01 boundary has to translate them.
