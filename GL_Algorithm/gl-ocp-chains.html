A standalone coverage part with its own premium function, and a 2027 rewrite

OCP is not an endorsement to the CGL. It rates per classification, with no territory, no deductibles, no size of risk and no package modification factor. Rule 5's standard premium computation does not apply, and the premium is a piecewise function of the job's cost with a breakpoint at $1,000,000.

The edition decides almost everything. Pre-2027 has a published loss-cost path and three class-specific premium branches. CW 2027 deletes the loss costs, two of those branches and the minimum premium, and leaves an ELP-only chain. The engine picks the edition the same way as for every GL subline, from the state package's declared parent: all 51 jurisdictions are on pre-2027 today. On 2027-04-01, 46 move, and CA, GA, NJ, NY and WA stay.

Pre-2027 chain
11 + 10

Rate-build and premium steps. Loss cost or ELP, three class branches (standard, Workers Comp-derived 15191, unit-rated 27111/27112), and a policy-level minimum premium.

CW 2027 chain
6 + 6

ELP only, one premium function, and no minimum premium. A $1 floor applies, but only when the unrounded premium is exactly 0.

Above the breakpoint
$0

Every filed over-$1M and over-100-unit cell is 0 in all 51 states, in both editions. Cost above the breakpoint adds nothing.

What to notice

  • Two fields gate the chain. The class code drives the loss cost and the premium formula. The class description drives the ELP (pre-2027) and the ILF (both editions). A submission with the code but no description gets no ILF and prices 0 pre-2027, or $1 in 2027.
  • The ILF limit keys are "1,000,000" / "2,000,000" in every edition. OCP never had the " CSL" suffix, so the 2027 renaming that breaks stale Premises and Products keys does not touch it. New York overrides SetILF, the only state override that affects premium.
  • Policy totals on ISO's sample OCP submissions include endorsement premiums (a PFAS exclusion, a terrorism exclusion). Those are separate coverages and not part of this chain.
No oracle. ISO's corpus has no rated OCP output to compare against. Every branch here is ISO's rule XML as the engine executes it, and the old Arkansas 15191 example (13,125 at 2023-05-01) is reproduced by the engine. That confirms the engine runs the rules as written. It is not an ISO-certified premium.

What to notice

  • The loss cost is gated on the class code, and the ELP and ILF on the class description. With the code but no description, BaseRate still comes from the loss cost but the ILF is 0, so the premium is 0.
  • The base rate takes the loss cost when it is not 0, otherwise the ELP. All 51 states file the loss-cost table today. The ELP text selector ("Rate/Loss Cost Applies", "Industry", "Company") matches the filed data, but the rule branches on the number.
  • The minimum premium borrows Premises' table at a hardcoded key "2" and uses no AdditionalInterestFactor. It feeds only the policy-level top-up, which is 0 on filed data.
  • The unit-rated classes read the same exposure field as a count of units, with the breakpoint at 100 and no /1000.
Silent zeros, 2026-10-05. Four routes price a classification at 0: a blank class description, a Company class with no ELP override (ISO messages it, and underwriting mode raises R29), class 15191 with no Workers Comp rate (ISO messages it, no referral), and any premium that rounds below 0.5. A blank description raises nothing in either mode.
Engine layer. The OI-94 refusal fires when a class has no loss-cost row in the state. That is the only point where the engine stops a pre-2027 OCP rating that ISO's rules would price.

What to notice

  • The $1 floor tests the unrounded sum, unlike Premises and Products, which test the rounded premium. A premium of 0.23 rounds to 0 and stays 0. Only an exact 0, such as a missing ILF or a null ELP, gets the $1.
  • SetELP now gates on the class code, not the description. The ILF still gates on the description, so a blank description prices at $1 rather than 0.
  • The retired classes are gone from the state tables, but nothing rejects them. They price at $1 with no message, no referral and no refusal.
  • LookupPrincipalsProtvLiabFactor remains in the file with no caller (E14).
Silent outcomes, 2026-10-05. $1: a blank class description, a retired or unfiled class, a Company class with no override (ISO messages it, R29 in underwriting). 0: any premium that rounds below 0.5, and a blank class code. Only the Company case reaches a referral.
vs. pre-2027. One premium function instead of three, ELP instead of loss cost or ELP, and no minimum premium. FinalRate, the ILF rule and the $1M breakpoint are unchanged, so a standard class moves only by the change in its rate source: the filed 2027 ELP against the pre-2027 loss cost.
