Eighteen chains across seven sublines, none of them a template

Unlike CF's four cause-of-loss forms rated in parallel off one shared shape, GL's seven sublines share almost nothing structurally — Premises/Operations forks by countrywide edition, Products/Completed Operations forks by whether a published loss cost is filed as zero, Owners & Contractors Protective forks by class code and by edition simultaneously, Railroad Protective forks by class code four ways with three "naming trap" rules whose names lie about which class they test, and Product Withdrawal / Cyber reads its host coverage's already-computed values rather than its own tables (escalation E18). Liquor Liability is the plainest of the seven: no loss-cost path exists at all, by rule — Rule 45.E says "for rates, refer to company," so the entire chain is an ELP-driven surrogate.

Dashed amber-and-rust nodes mark a flagged finding — an unresolved formula, a naming trap, a sibling-group dependency, a table that prices legitimately at zero — logged in each subline's own RatingAlgorithms.md and its source gate doc rather than guessed at. Where a gate doc did not reconstruct a step's internal branching, the node says so instead of inventing one.

What to notice

  • Two separate "silent referral" paths converge on the same rate build-up: a missing premium basis 1000x-overcharges (falls to the raw-exposure branch), and a missing class/territory silently routes onto the ELP path — neither raises a flag.
  • Every "Per Claim" deductible row publishes a real-looking `0` factor, guarded only by a validation rule that fires on override absence, not by the rating chain itself.
  • Medical payments is a separate, additive, 0-decimal charge in this edition — folded into the ILF only under CW 2027 (see that chain).
