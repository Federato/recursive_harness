Four classes rated off one 18-cell table, and a constant borrowed from OCP

Railroad Protective shares subline 335 with Owners & Contractors Protective but has its own rule (49) and rule file. ISO files no railroad loss cost anywhere. Rule 49.E.1 says "Refer to company", and the real procedure is ELP Supplement 5.E. Each state files an 18-cell base ELP table (three classes × six trains-per-day bands). The fourth class, 40014, is derived as 150% of OCP's figure for class 16292, Construction Operations – Owner.

Every class is rated per $1,000 of total cost. The edition is picked the same way as every GL subline: all 51 jurisdictions are on pre-2027 today. On 2027-04-01, 46 move, and CA, GA, NJ, NY and WA stay. Railroad's 2027 rewrite is the largest of any GL subline: 65 rules become 46.

Pre-2027 chain
21 + 10

Rate-build and premium steps. Mixed-hazard weighting for 40011, a 10% supervisors add-on, a work-trains charge for 40013, and a policy-level minimum premium.

CW 2027 chain
12 + 3

Add-ons and minimum premium withdrawn. One FinalRate rule branches on all four classes, and the $1 floor has no exposure test.

Base ELP at 2027-04-01
× 0.5

Every filed base ELP cell is exactly half its 2026 value in the states checked, and the 16292 factor moves from OCP's loss cost to OCP's ELP.

What to notice

  • Rule names in this file cite class numbers they do not test. SetBaseELPRR400145orLess and SetBaseELPRR40014 both act on class 40011 and write to DataDefs named for other numbers (…400065orLess, …40006). SetFinalRate40011 tests class 40012. Only SetILF40014 → ILF40014 means what it says.
  • The modifiers are Experience × Expense × Schedule. That differs from OCP and Liquor, which use ModToUse, and Liquor also uses PackageMod.
  • The limits are each occurrence and aggregate, with no " CSL" suffix in any edition. Only AK and NY override any rule in this file, and only for statistical coding.
No referral ever fires. Railroad has no Company selector (every RailroadELP row is "Industry"), no ISO override message, and no loss-cost node for the OI-94 refusal. Underwriting mode raised nothing on any probe. Operations other than construction (Procedure 5.E.1.b) are a manual referral with no ERC discriminator (OI-45).

What to notice

  • Every rule runs for every class. The class forks are inside the rules, which is why the diagram branches on class four separate times.
  • The base premium is rounded to whole dollars before the 10% supervisors add-on is computed. On 40012 that add-on is figured at the 40011 rate.
  • The work-trains rate (56.8 per $1,000, a rare countrywide dollar rate) is computed for every class but charged only on 40013.
  • When a 40011 project is partly clear of the tracks, the clear part is rated on the 40014 basis. For 40012 it is simply dropped, so a project two-thirds clear prices on its hazard third alone.
Silent zeros, 2026-10-05. A blank trains-per-day band, a blank class description and an unknown class code all price 0 with no message and no referral. A missing contract-cost ratio on 40013 and a zero exposure also price 0, but ISO messages both.
No oracle. ISO's rated golden case carries Railroad switched off. The engine rates ISO's RI, NH and MN Railroad sample submissions end to end, which confirms it runs ISO's rules as written, not that the premiums match ISO.

What to notice

  • The $1 floor tests only the rounded premium. Unlike every other GL subline here, it has no exposure test, so a classification with zero exposure prices $1 while ISO messages "Exposure must be entered".
  • The supervisors add-on and the work-trains charge are withdrawn. An election of supervisors coverage, or a work-train cost on 40013, is accepted and ignored.
  • The mixed-hazard 40011 rate is now rounded once over both parts, not once per part.
  • The base ELP halves, and 16292 moves from loss cost to ELP. A standard class's 2027 premium is roughly half its 2026 premium at the same ILF.
Silent outcomes, 2026-10-05. $1: a blank band, a blank description, an unknown class, zero exposure and a missing 40013 ratio (ISO messages the last two). Ignored: a supervisors election and work-train cost. Still unrated: the clear part of a 40012 project.
vs. pre-2027. The same four classes and the same ILF table. A single FinalRate rule replaces the six mixed-hazard and supervisors rules, every add-on and the minimum premium are gone, and the floor arrives without an exposure check.
