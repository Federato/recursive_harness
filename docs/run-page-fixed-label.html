The comparison is by state — so what should the count be called?

The rule is settled: a state that was failing last run and is not failing now counts. The only open thing is the label, because “fixed” claims a measurement the loose rule does not make.

Mockup. Invented numbers, real awkward case.
Four states qualify: CA failed at 1M × middle and passed at 1M × middle this run — measured. GA and OH failed at 1M × highest, a configuration this run did not include. RI failed on 15 August in a run that was stopped before reaching it again.
1 · Call it “no longer failing” One word changed. Under the by-state rule that sentence is exactly true of all four, with no caveat and no second number.
Slightly cooler than “fixed”, and a reader in a hurry may read it as the same thing anyway — which is fine, because it does not assert anything false when they do.

The most information, and the only version that lets you tell at a glance whether a fix was actually demonstrated. One more number to compute and one more thing on the card.
