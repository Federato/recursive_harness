## In plain English first

For these ten endorsements ISO publishes no rate. The underwriter decides
the charge and types it in (`ManualPremium`); ISO's rules only apply the
policy-wide adjustments chunk 14 proved (package discount, multi-premium
credit, IRPM) and round to whole dollars. So the arithmetic is small. The
work is making sure each one reaches the right adjustments, rounds the way
ISO does, and is switched off in the states that switch it off.

**Three things that shape the plan:**

1. **The risk is in the plumbing, not the arithmetic.** One formula, but the
   modifiers are read through seven different relative depths. RC-1 resolves
   every path on a real tree before any golden case.
2. **Rounding differs by variant.** Three roundings (A), two (B), one (C).
   RC-2 takes one golden case per variant, each chosen so the variants would
   give different dollars.
3. **The states act by switching off, not by rewriting.** GA, TX, VA and FL
   each silence a family in a different way (empty `ErcRate` vs coverage
   indicator 0). RC-4 predicts and confirms each one live.
