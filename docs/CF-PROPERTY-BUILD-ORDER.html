Property — build order, by coverage

Written 2026-09-16. Item 3 of CF-PROPERTY-INTEGRATION-PROPOSAL.md — "a coverage-by-coverage gated build order" — unauthorized since 2026-08-20. This is the plan, not the authorization. Markdown companion: CF-PROPERTY-BUILD-ORDER.md.

Scope: this is the harness, not the Excel rater. The deliverable is a cf_engine/ package in Recursive_Harness_2.0 that executes ISO's ERC rules, alongside gl_engine/ — golden cases, gates, an interpreter. It is not a plan for CFRater1.01.xlsb in C:\Projects\Spreadsheet_Rater. The two share evidence and nothing else: the Excel-rater tracing and the extracted Supporting Tables appear below as inputs that save work, because the ERC reading behind them is the same reading the engine needs. Where a chunk says “traced”, that means the rules are understood — not that any code or formula exists.
Nothing here gets built until you say so. The order is sequenced on data dependency, not on size, and every claim is drawn from work already filed in CF_Algorithm/.

The order

0 Foundation — not a coverage, gates every coverage

Deliver a cf_engine/ that can load, resolve and execute a CF package.

  • Interpreter parity: rul:Product, rul:Power (Leasehold needs it — the only use in the package), rul:FirstNonNull, and rul:Choose first-match semantics, which Legal Liability depends on.
  • Resolver: countrywide base, state child, edition chain. CF state packages ship only what changed, so a table absent from the current edition is still in force from the last edition that filed it.
  • A county/place territory resolver. Not ZIP.
  • A header-only-table detector that fails loudly rather than resolving to zero.

Unblocks everything. No gate of its own — it is proved by chunk 1's gate.

1 Building — Basic Group I, class-rated, scheduled

The spine: base rate → territory → protection class → cause-of-loss adjustment → coinsurance → LOI → deductible → premium.

Why first every other coverage is described relative to this one. Contents, Business Income, Special Class and SCBI all copy its rate, borrow its keys, or diff against its formula.

Known traps DeductibleFactor keys on the location total (Building + Contents), not the building limit. Sprinkler leakage has two mutually exclusive terms and an LCM rounding quirk.

2 Building — Basic Group II

Why separate it needs machinery chunk 1 does not. BasicGroupIIRate and LowestBasicGroupIIRate have zero countrywide rows. 45 states file the first, 39 the second; FL and PR file neither, and AR, DC, KS, NY, RI and TX also lack the lowest table. There is no CW fallback — the state row is the only row. This chunk proves the state-table loader for real.

Known traps the wind/hail-excluded branch rebuilds from the lowest base rate and silently drops the class hazard load. BasicGroupIISymbol is a submission input on Special Class — no rule derives it.

3 Building — Broad and Special

Short chains, and where two more behaviours appear: hardcoded literal lookup keys ("Frame", "Bldg") and the theft-exclusion factor.

Known trap SpecialBuildingRate is another zero-CW-row table — 45 states file it, FL and PR do not.

4 Contents (Personal Property) — all four forms

Build differentially against chunks 1–3; most of the chain is shared and what differs is already documented.

Known trap CovForm, not CovType, drives the Contents branch — and it is inherited from the occupancy class, so contents items cannot differ within a class.

5 Business Income — the Factor chain and all four forms

New machinery SetFactor is a four-way Choose that picks exactly one of MaxPeriod, MonthlyLimit, ExtraExpense or TypeOfRisk. Multiplying them would overstate the premium by a large multiple. Plus the combination blends and the educational branch.

data already extracted all seven Factor tables are in BusinessIncome_FactorAndEnums_Tables.xlsx.

Known traps BI has no deductible, no LOI and no coinsurance factor — its Factor is the coinsurance analogue. The educational branch defaults to 0.0, not 1.0.

6 Special Class — building side

Two fewer paths RatingType (Specific/Tentative) and Legal Liability are both confirmed structurally absent.

Known trap the base rate keys on class description via SpecialClassDescConvertedOption, not class code — and FL files 11 description strings that do not exist countrywide, so a CW-derived list silently misses in Florida.

7 Special Class Business Income

The most differential chunk in the plan — a reuse map already gives a per-value verdict of copy, share the table, or build own.

Known traps BGI copies the parent's finished rate while BGII runs its own lookup; Broad reads the same table as Building at a different row (0.015 vs 0.011 / 0.023); Special reads entirely different tables despite identical rule and datadef names.

8 Legal Liability — Building and Contents already traced

Implementation, not derivation: both coverages, all four forms each, with an eleven-point divergence map and only two of the eleven moving money.

The shape the fork is in SetPremium, not the rate chain — it starts three steps earlier and discards coinsurance, LOI and deductible. Blanket is unreachable on this path.

9 Blanket rating widest remaining gap

Branch B is a stub in every premium file built in chunks 1–8, across every coverage. Doing it once, late, is cheaper than doing it five times early — but nothing above this line is finished until it lands.

10 Earthquake — the fifth form, all coverages largest unblocking item

97 rule files, and it gates more than itself: roughly 29 Special Class files ship an Earthquake wrapper, Legal Liability has 8 Earthquake endorsement variants, and Non-Owned Trailers has its own. Its own EQFactor, EQ territory, EQ class, sub-limit and flat-dollar-deductible variants.

11 Leasehold Interest — a sixth coverage, not a fifth path

32 rule files, its own datadef group, four sub-coverages (Tenants Lease, Bonus Payments, Improvements & Betterments, Prepaid Rent) × five forms.

Its exposure is computed, not entered a present-value annuity — AnnuityConstant × (1 − DiscFactormonths), averaged inception-to-expiration — driving the only rul:Power in the package. No coinsurance, LOI or deductible anywhere in it, and no blanket branch at all (confirmed, not assumed).

12 The endorsement families

Sized, not sequenced — take them by family once the core is proved: Ordinance or Law (55), dependent properties, utility services, green upgrades, debris removal, unmanned aircraft.

13 Terrorism / TRIA

16 rule files. Reads other groups' finished premiums, so — as in GL — it runs last.

14 Policy assembly

Aggregation, minimum premium, statistical coding.

The per-coverage gate

Mirrors GL's, with the evidence Property actually needs. A chunk passes when all nine hold.

#Gate conditionWhy it exists
1A golden case rates end to end, every intermediate traced to a named rule and a named table rowGL's standard; nothing weaker caught GL's edition split
2Every table the chain touches has its row count stated, and any header-only table is explained22.4% of CW tables are header-only
3Every state enumerated, not sampled — “n of N” with N from the corpusGL's five wrong figures were all aggregates or negatives
4Every 0 tested against its consuming branchCF already has three meanings, one of which collapses the premium
5Every hardcoded literal key listed"Frame", "Bldg", "Other than Apartments and Condominiums", class 1180 — each makes filed rows unreachable from that chain
6Shared-name traps diffed, not assumedSame rule name and datadef name already found reading different tables
7Every exclusion's endorsement record identified per datadef groupVandalism, wind/hail and theft each file a separate record per coverage (S-1/S-2/S-3)
8The edition basis stated; any table from an older edition says soSeveral live tables exist only in earlier packages
9The golden case comes back with no unexplained validation message — each one designed out, or logged in CF_Message_Register.md with its rule, its cause and the check that was missingA CF submission can rate correctly and still return errors: ISO has one severity, not three. 1,621 DoMessage rules across 48 jurisdictions, and 316 are switched off by a state — so the countrywide set is not the applicable set. Some rules come in mirrored pairs, so attaching a form to silence one can raise its opposite. Diagnose with scripts/cf/07_diagnose_message.py

Recommendation. Chunks 0 → 1 → 2 is the smallest sequence that proves the architecture — 0 proves the loader, 1 proves the interpreter against a full chain, and 2 proves the state-table resolution that 22.4% of the corpus depends on. Everything after that is repetition with known traps. If only one thing is authorized, make it chunk 0 plus chunk 1's gate: a passing gate on Building Basic Group I answers whether GL's architecture transfers to Property at all, which is still the open question from the August proposal.
