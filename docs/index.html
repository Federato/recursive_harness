How to read this

This page is meant to be opened from a local clone, not served. GitHub Pages is not enabled on this repository, and GitHub shows HTML as source rather than rendering it — so the HTML links above work only after cloning, while the markdown links below render fine in the browser on GitHub.

What is deliberately not in this repository

ISO's licensed content. The manuals, the machine-readable rating packages, the text extracted from them, and ISO's rated example policies are all excluded — see .gitignore.

The engine reads the ERC corpus from outside the repository, at a path set by the GL_ERC_ROOT environment variable. Without a licensed copy of that corpus the code will not run — the documents, the method and the reasoning are what this repository is for.

Every figure in these documents is measured from the ISO corpus and reproducible from the scripts in this repository, with one stated exception: the descriptions of Duck Creek and Guidewire are public architectural summaries, not verified internals.
