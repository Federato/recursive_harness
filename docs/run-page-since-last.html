“What changed since last run” — three ways to place it

The proposal's W3 leads with it: new problems, problems fixed, still open, newly covered ground. It is the one element of section 6 we have not placed. Everything else on these pages is already agreed — verdict, lead visual, matrix, table.

Mockup. Invented numbers. Same run throughout: L3 Limits, class 91340, compared against the previous L3 run of the same class on 15 August.
1 · One block, directly under the verdict Four counts comparing this run with the previous run of the same layer and class, computed when the file is written and frozen into it. The rest of the page is untouched.
Answers “did my change help” in one line. Needs a rule for what counts as “the previous run” — and a first run of anything has nothing to compare against, so it has to say that rather than show four zeros.

The most informative and the busiest. Two extra states to render in every cell, and a run with a lot of churn gets noisy.

Nothing to define, nothing to get wrong, and no risk of a file quietly comparing against the wrong predecessor. You answer “did my change help” by opening two files.
