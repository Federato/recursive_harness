The habit that produced every finding

Derive the expected numbers by hand from the filed rows FIRST, write them down, then run. Every finding worth having in this project came from a prediction disagreeing with the engine — Arizona, the BCEG zero, the Kansas wind/hail mechanism, the cumulative forms. Observing what the engine does and writing that down proves nothing.
