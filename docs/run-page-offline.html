The offline run — no ISO answer, so no agreement

Everything agreed so far assumes a comparison: a verdict percentage, red cells, a “no longer failing” count. An offline run has none of that. It is also the run you make first, every time, and often the only one you make.

Mockup. Invented numbers. Same L3 run as the other pages, but engine-only: 612 ratings, 0 ISO calls, free, about five minutes.
1 · The same page, asking what it can actually answer The frame does not change. What changes is the question each part answers: not do we agree with ISO but did our own engine behave sensibly. The verdict counts what rated and what refused. The matrix colours by whether the premium moved. The curve is still a curve — it is our premium against the limit, and a kink is a defect signal with or without ISO.
One page to learn. It must be unmistakable that no comparison happened, or an offline run reads as a passing run.
