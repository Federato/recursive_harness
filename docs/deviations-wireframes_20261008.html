What this screen is for

  • A filing is one state × one line × one version with separate new and renewal dates D4.
  • Rows are LCMs or ISO table overrides D1, narrowed by class, class group, territory or limit D3.
  • Every row picks replace or multiply D7. “Result” shows the value the engine will actually use.
  • Compiled (read-back) shows the ISO-shaped tables this produces, so a disputed premium can be traced to them I1.
  • Approved versions are read-only. Editing one starts a new draft.
  • “Applies to” fans one draft out to several states. Each becomes its own filing I2.
