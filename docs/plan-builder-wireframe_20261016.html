Test Plan Builder · option

Plan a round of checks

Describe one risk the way you would fill in a submission, mark the fields you want to try several ways, then apply it to as many states as you like. The cost is shown before anything goes to ISO. General Liability, with live field lists and coverage counts from 2026-10-16.

Wireframe notes
  • Every field sits where it would on a submission, grouped into six short screens instead of one 38-row list. Two columns on a laptop, one on a phone.
  • Each field has a single value (the risk) and a Vary switch. Switched on, it shows ISO's values with the two edges already picked. This maps onto today's plan: fixed fields become the plan's base risk, varied fields become its dimensions.
  • The brown "rated in N of 51 states" line under each field comes from the Coverage Board, so the gaps are visible while choosing.
  • States are picked last, on a map, with quick picks. Fields a state does not offer are named there, so nothing is silently dropped.
  • The cost on the right is a rough estimate in this wireframe. The console counts it exactly, building each request and subtracting every answer ISO already gave.
  • "Sweep" keeps today's way of working (choose fields, try every pair) for anyone who prefers it; presets and "fill gaps" prefill the same screens.
